# 文件重命名规范（file-rename-convention）

> 一个 WorkBuddy / CodeBuddy Skill：把“新建 / 另存 / 重命名”动作统一成规范文件名，并自动维护版本号。

## 这是什么

任何新建、另存为、重命名、保存文件时，都按统一规范生成文件名，并自动推算下一个版本号，
免去手动记忆「v 几」「日期要不要更新」的麻烦。

标准文件名结构：

```
文件名-文件类型-时间-v版本号&备注.扩展名
```

示例：`平台首页效果预览-效果预览网页-20260801-v2&微调了UI布局.html`

## 版本递增规则

| 场景 | 版本变化 |
|---|---|
| 首次创建（目录无同名主题） | `v1`，日期取当天 |
| 跨天再改（哪怕只改一点点） | 主版本 +1（`v1→v2`），日期更新 |
| 大篇幅重构 / 大改 | 主版本 +1（`v2→v3`），进位时次版本清零 |
| 同一天多次小幅修改 | 次版本 +0.1（`v1→v1.1→v1.2`），日期不变 |

日期固定格式 `YYYYMMDD`（如 `20260801`）。「文件类型」是中文描述（合同 / 数据表格 / 效果预览网页），
与扩展名（docx / xlsx / html）分开写。

## 如何安装

把本文件夹整体复制到你的 skill 目录：

- 用户级：`C:\Users\<你的用户名>\.workbuddy\skills\`
- 项目级：`<你的工作目录>\.workbuddy\skills\`

重启 / 刷新对话后，在对话框里说「按命名规范建一个文件」即可触发。

## 如何使用

当你要创建 / 保存 / 重命名文件时，告诉我四个要素：**文件名主体、文件类型描述、扩展名、备注（可空）**。
我会运行下面的脚本帮你算出规范文件名：

```bash
python "<skill目录>/scripts/suggest_name.py" \
  --theme "平台首页效果预览" \
  --type "效果预览网页" \
  --ext html \
  --note "微调了UI布局" \
  --dir "<目标目录>" \
  [--major]            # 大篇幅重构 / 大改时加此参数
  [--date 20260801]    # 需要指定日期时
```

脚本输出即最终文件名；加 `--json` 可查看版本拆解明细。

## 文件结构

```
file-rename-convention/
├── SKILL.md                  # 技能定义（触发词、工作流）
├── scripts/
│   └── suggest_name.py       # 确定性版本计算引擎
└── references/
    └── examples.md           # 规范详解与版本规则表、用户原始案例
```

## 说明

- 备注里的 `\ / : * ? " < > |` 等特殊字符会被脚本自动清洗为空格，无需手动处理。
- 拿不准是否「大改」时，默认按同日小幅处理（次版本 +0.1）；仅当你明确说大改/重构，或文件日期与最新版本不同，才主版本 +1。
